# barcode-generator

Website chính thức: [https://designforge.site/](https://designforge.site/).

Link GitHub Pages cũ tự động chuyển người dùng đến website chính thức ngay khi
mở trang. Chuyển hướng dùng `location.replace()` để tránh lặp khi bấm Back,
kèm meta refresh dự phòng khi JavaScript bị tắt.

Sau khi đẩy thay đổi lên nhánh đang được GitHub Pages sử dụng và quá trình
triển khai hoàn tất, chuyển hướng sẽ có hiệu lực trên link cũ.
